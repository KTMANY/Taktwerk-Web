# TaktWerk – High-Conversion SaaS Landing Page für Handwerksbetriebe

Diese Version (`v2`) ist zu 100 % auf die Zielgruppe **Handwerksmeister / Betriebsinhaber** zugeschnitten. Technische Interna (wie NAS/Container-Details) wurden komplett entfernt – stattdessen stehen Zeitersparnis, mehr abgerechnetes Material, kinderleichte Bedienung für Monteure (Sprache & WhatsApp) und die enorme Lizenzkosten-Ersparnis als Zusatz zu bestehenden ERP-Systemen im Zentrum.

## Enthalten im Paket
- `index.html`: Komplette, sofort auf GitHub Pages lauffähige Webseite inkl. interaktivem Ersparnis-Rechner und eingebauten Modals für Impressum, DSGVO & AGB.
- Platzhalter-Variablen (z. B. `{{FIRMENNAME_PLATZHALTER}}`, `{{PLZ_ORT}}`, `{{UST_ID}}`) am Ende der `index.html` im JavaScript-Block `legalTexts` zentral anpassbar.
